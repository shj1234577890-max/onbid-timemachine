# 온비드 타임머신

> **"10년 전 그 공매, 지금은 어떤 가치가 되었을까요?"**
> 10년 전 온비드 공매로 아파트를 샀다면 지금 얼마를 벌었을지 보여 주고, 앞으로 10년의 시세 흐름을 예측해 보여 주는 웹앱입니다.

- 대상: 대구·경북 아파트, 2015~2017년 낙찰 사례
- 목적: 공매가 좋은 기회일 수 있다는 점을 숫자로 보여 주어 온비드에 관심을 갖게 하고, 낙찰가율 향상에 기여하기
- 만든 사람: 서혜정
- **접속 주소:** https://onbid-timemachine.vercel.app
- **저장소:** https://github.com/shj1234577890-max/onbid-timemachine

> ⚠️ **지금은 예시 데이터(28건)로 동작합니다.** 화면 맨 위에 "예시 데이터" 띠가 표시됩니다. 실제 공매 사례가 아닙니다.
> 예측은 참고용이며 실제 수익을 보장하지 않습니다. 투자 권유나 투자 상담이 아닙니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 지역 선택 | 대구/경북 → 시·군·구를 고르면 사례 목록이 나옵니다. 고른 지역은 주소에 남아 "← 목록으로"로 돌아와도 유지됩니다. |
| 그때 샀다면 지금 얼마? | 감정가, 낙찰가(감정가 대비 낙찰가율), 현재 시세, 시세 차익, 수익률을 보여 줍니다. 손실 사례도 빼지 않고 "손실 −12.3%"처럼 보여 줍니다. |
| 10년 예측 그래프 | 낙관·기준·비관 3가지 범위와 물가 기준선(연 2%)을 그리고, "2036년 예상 수익률"을 범위로 보여 줍니다. 안내 문구 2종이 항상 함께 표시됩니다. |
| AI 해설 | 계산된 숫자를 AI가 쉬운 말로 풀어 줍니다. AI는 숫자를 새로 만들지 못하고, 단정·권유 표현이 나오면 해설을 숨깁니다. |
| 온비드 연결 | "온비드에서 지금 나온 물건 보기" 버튼으로 온비드 부동산 물건 목록으로 이동합니다. |

## 지키는 원칙

- **계산과 예측은 정해진 공식으로 코드가 합니다.** AI는 해설만 씁니다.
- 데이터에 없는 값은 지어내지 않습니다. 현재 시세가 없는 사례는 목록에서 뺍니다.
- "사세요", "파세요", "최적의 매도 시점", "반드시", "확실히" 같은 단정 표현은 화면과 AI 해설 어디에도 쓰지 않습니다.
- 동·호수와 낙찰자 정보처럼 개인을 알아볼 수 있는 정보는 다루지 않습니다. 로그인과 회원 정보도 없습니다.

## 기술

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Recharts(그래프) · OpenAI `gpt-4o-mini`(해설) · Playwright(화면 자동 테스트) · Vercel(배포)

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
```

AI 해설을 보려면 프로젝트 폴더에 `.env` 파일을 만들고 `OPENAI_API_KEY=...`를 넣습니다. 키가 없어도 앱은 동작하고, 해설 칸만 보이지 않습니다. `.env`는 `.gitignore`에 등록되어 저장소에 올라가지 않습니다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `npm test` | 계산·표시 규칙·금지어·데이터 형식·요청 검사를 자동 채점 |
| `npm run lint` | 코드 검사 |
| `npm run build` | 배포용 빌드 (타입 검사 포함) |
| `npm run backtest` | 예측 검증 (사례별 오차 출력) |
| `npm run check:secrets` | 비밀 키가 커밋·빌드 결과에 없는지 검사 (build 뒤에 실행) |
| `npm run test:e2e` | 화면 자동 테스트 17개 (컴퓨터에 설치된 Chrome 사용, 빌드부터 알아서 함) |
